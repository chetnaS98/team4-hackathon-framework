# Synthesis (findings, readouts, insight docs)

Keep the source's findings, wording, structure, IDs, quotes, and confidence/severity ratings exactly. Do not restructure into a new template, rewrite findings as new sentences, or add ratings.

- Use the source's own headings. Insert headings (via `sections`) only where a long stretch has none, one per finding/theme, so each chunk is retrievable alone.
- Overview: n, personas, dates, what the document covers (only what the source states).
- List the underlying transcripts in `related`.
- Charts, affinity maps, journey images in the source: figure block where they appear (embedded image + **Transcription:** with every label, count and value shown).
